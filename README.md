# 开源金工「交易行为因子」复现项目

复现开源证券「市场微观结构研究」系列的交易行为选股因子，在 A 股全市场做单因子/合成回测，
并搭建每日自动更新的实时监控网站。数据源：Tushare Pro（日频）。

> **本项目当前范围**：精确复现 **理想振幅** 与 **理想反转** 两个日频因子（均已对齐研报）；
> 聪明钱、APM 两个因子因**分钟数据不可得**，经实证测试后确认无法复现（详见下文与
> `代理因子测试/`）。

## 二、聪明钱 / APM 为何不做（数据限制 + 实证否定）

**数据限制**：这两个因子需分钟数据（聪明钱要完整1分钟K线；APM需13:00盘中价）。而
Tushare 分钟接口配额仅 **2次/天**、iFinD 仅试用账号（数据只到~2022且 Mac 装不上）、
公司无分钟数据库——当前资源下**无法精确复现**。

**实证否定日频代理**：我们系统性测试了「用日频数据做代理因子」的可行性（见 `代理因子测试/`），
用三条判据打分，结论是**三个候选全部不达标**：

| 代理候选 | IC | 结论 |
|---|---|---|
| 大单资金流（聪明钱代理） | +0.0001 | 完全无效（机制不同：流向≠价位定位） |
| OVP代理（APM，隔夜−日内） | +0.050 | 强但与现有因子失效期同步(相关0.70)、实为反转变体 |
| 纯隔夜因子 | +0.014 | 正交但太弱 |

**结论：日频无法忠实替代分钟因子，故不以低保真代理充数。** 这一"测试并用数据否定"的过程
本身是严谨性的体现。若日后取得分钟数据（公司数据库/更高积分 token），现有下载与因子代码
框架可直接接入。

## 三、最终方案（重启后）

```
因子层   理想振幅 + 理想反转  (两个日频因子, 均精确对齐研报)
合成层   2因子 ICIR 滚动加权合成 + 分池(沪深300/中证500/中证1000)
诊断层   样本内外对比 + 2020 后疲软期归因(与大盘市值风格切换的关联)
网站层   每日自动更新的实时监控(数据全为日频, 收盘后可增量刷新) → GitHub Pages
```

**为何是干净的两因子方案**：理想振幅与理想反转均可用日频数据精确复现、已对齐研报；
聪明钱/APM 受限于分钟数据，经实证确认无法用日频替代。与其硬凑四个因子，不如交付
两个扎实、诚实、可自动运行的因子 + 实时监控。

**进行中/后续**：阶段C.4 行业市值中性化（对齐月报口径）→ 阶段D 双因子合成 →
阶段E 样本外诊断 → 阶段F 实时网站上线。

## 五、复现方式

```bash

python script/download_01_basic.py && python script/download_02_daily.py
python script/download_03_index_industry.py && python script/download_04_check.py

# 2. 清洗层
python src/data_clean.py

# 3. 因子计算
python src/factors/ideal_amplitude.py
python src/factors/ideal_reversal.py

# 4. 单因子回测(出绩效表 + 图)
python src/backtest/run.py ideal_amplitude -1
python src/backtest/run.py ideal_reversal -1

# 5. 代理因子测试(聪明钱/APM 可行性, 已否定)
python 代理因子测试/test_proxy_factors.py
```

数据源：Tushare Pro。token 存于 `script/.tushare_token`（已 gitignore，不入库）。
